# us-trip-2026

Trip HQ for San Jose + New York, Sep 23-28, 2026.

Single-file static app (`index.html`) - itinerary timeline, bookings with
confirmation numbers, open decisions with persistent checkboxes, and a
logistics cheat-sheet. No build step, no dependencies.

Live: https://yoavgal10.github.io/us-trip-2026/
